# 0.2.1 编辑修正与验证

用户实际反馈：索尼游戏手柄的成稿以品牌筛选、内部比较分析和参数核对说明为主，不能作为宣传文案。原来的四阶段结构并未解决这个编辑边界。

## 修正

- 提示明确区分发布渠道、商品事实、创意表达和编辑提醒。允许创作情境、节奏与情绪邀请，不补造型号、性能或兼容信息；稀疏输入可写短广告，未知参数放在 warnings。
- 加入面向常见中文宣传类型的狭窄检查，发现内部筛选分析、泛化详情页占位说明后，把真实原句与修改建议传给审稿并保留在结果中；定稿仍有问题就使用现有预算改稿，耗尽失败，不替换成预写文案。
- 保留明确要求的披露及其合理措辞变化；指南/客服等非宣传类型、已知使用限制不应被这项检查误伤。规则不是通用语义审核或营销评分。
- 加入用户原文的回归测试，以及 sparse-controller 真实模型对照样例。输入是依据成稿重建的最小输入，未冒称恢复了用户原始表单。

- 全量 pytest：132 passed。
- 本轮专项与流程测试：21 passed；独立审查提出的一处披露措辞误拦问题已复现、修正并复核通过。

## 仍未验证

当前没有可用的真实模型配置，因此没有复现用户模型的完整生成轨迹，也未证明修改后的实际文案足够好。脚本化测试能证明原例不会被指定流程直接放行、修改意见确实传递，不能证明说服力或转化效果。提示中的编辑示范是人工编写，不是 Agent 实测输出。

真实对照入口见 README，样例为 sparse-controller。0.2.0 的实现与安装证据另存 [历史记录](verification-v0.2.md)，不作为本次营销质量证明。
