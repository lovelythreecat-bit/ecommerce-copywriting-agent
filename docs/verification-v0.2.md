# 营销工作流 0.2.0 实现与验证记录

日期：2026-09-30。用户授权在原有独立 Python Agent 和最简桌面工具上，改进策划、营销资料依据、扩写和编辑流程。

## 已实现

- LangGraph 实际执行资料检索、策略、初稿、审稿、定稿。正常四次模型调用，默认最多六次，修复额度由各阶段共享并预留后续阶段。默认全流程超时 300 秒。
- 来源与模型接口分离。默认本地检索六张中文知识卡，来源为实际核对的 NN/g、Shopify 和 FTC 页面；详情见 [营销资料说明](marketing-sources.md)。这不是每次生成实时联网；在线检索由调用方注入。
- 保留 CopywritingAgent(model)、generate/agenerate 与 ModelAdapter；结果增加策略、初稿、审稿和来源，原结果构造字段仍可使用。
- 实际来源编号核验、审稿原句核验、存在编辑问题时的未改稿检查、来源摘要限制与深拷贝、累计用量和安全错误。
- 桌面提供正文、营销策略、初稿、审稿、资料来源五页；新请求清空旧产物，复制仅取最终正文，保留原有后台线程和关闭行为。
- 八组明确标注为模拟的跨品类样例，以及需显式 --run 的真实模型前后对比工具。每次运行使用独立目录与状态记录，盲评正文与来源映射分开。

## 审查修正

- 修复桌面格式化代码中的 Python 3.12 专用 f-string 写法，保持声明的 3.11 语法兼容。
- 自定义检索来源重新验证并深拷贝，避免篡改后的来源绕过验证或跨请求共享列表。
- 对照报告使用独立运行目录与完成状态，避免失败的新运行被旧报告误导；模型内容使用安全长度的代码围栏，不能伪造报告结构。
- 在线检索接入文档明确 origin="web"，防止默认本地来源标记被误用。

## 验证边界

- 当前进程没有真实模型地址、模型名和密钥配置，未进行真实模型文案前后对照；不能据此宣称自然度、说服力或销售转化已提升。可按 README 运行已提供的对照工具。
- 网页来源核对发生在开发阶段。默认运行时检索本地整理卡片，不保证平台政策或市场信息实时更新；它们提供写作原则，不提供商品事实证据。
- 模型审稿和本地规则都不能认证商品事实或完整评价营销质量；最终是否适合发布仍需实际审阅。
- Tk 检查使用真实控件但没有进行人工视觉或屏幕阅读器验收。
- 本目录不是 Git 仓库，没有创建提交或推送。旧版验证证据保留于 [0.1 历史记录](verification-v0.1.md)，不作为新版质量证据。
