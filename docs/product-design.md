# 电商文案 Agent 桌面工具界面约定

## 已确认基准

范围：`desktop/` 中用于手动测试 Agent 的 Windows 桌面窗口。依据：本项目已确认的最简原生 Tkinter 单窗口方案，以及[产品设计规格](superpowers/specs/2026-09-30-ecommerce-copy-agent-design.md)。

- 使用 Tkinter/ttk 原生控件，中文标签明确指出字段用途；自由填写文案类型，常见类型仅作为可编辑预设。
- 单窗口按“商品与写作要求”“模型连接”“生成结果”分区。较长输入与结果支持滚动，商品输入区在较小窗口中可滚动；沿用系统字体与显示缩放。
- 必填商品名称以星号标示；输入或配置错误在同一窗口的状态文字中说明，保留用户输入。状态文字也说明生成中、完成与复制结果，不能仅靠颜色区分状态。
- 生成期间禁用生成和复制，阻止重复提交；开始新生成时清除上次正文与提示。成功后仅复制当前正文；失败后不可复制旧结果。
- 生成结果使用原生可切换视图呈现“正文、营销策略、初稿、审稿、资料来源”；新请求及失败时清空所有旧产物。资料来源逐条标明实际来源类型，说明默认检索器使用本地资料，不把资料检索写成实时联网。
- 多阶段生成期间只提示流程可能耗时，不显示未经核心状态证实的阶段进度。
- 关闭窗口立即结束界面，不等待后台网络线程；界面不承诺取消已发送的模型请求。
- 视觉基准（2026-10-08 用户确认）：保留三分区，采用浅色工作台、白色面板和紧凑标题，使用统一间距；商品输入内按“商品信息”“写作要求”分组。仅“生成文案”使用蓝色主按钮，保留可见焦点及 active/disabled 状态，图片与复制操作使用次级按钮。
- 字体从系统命名字体派生，不设置 `tk scaling`；Text/Listbox 使用较小的请求宽度，由容器分配实际空间。模型说明与状态按容器宽度换行，结果正文与提示区保持清晰区分。主题数值和样式统一在 `desktop/app.py` 的 `_configure_theme` 中维护；最小 700×600 窗口需保留主行动、五标签和可读结果区。

实现入口为 [`desktop/app.py`](../desktop/app.py)。这份约定只适用于桌面测试工具，不替代核心包的公共接口契约。
